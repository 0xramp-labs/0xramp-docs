0xramp is currently in **public beta (v0.9)**. The core buy and sell flows are live at [0xramp.app](https://www.0xramp.app), and we're actively working toward a stable v1.0 release. This page tracks what's shipped and what's coming. For the most granular change history, follow the GitHub repository's releases page — a link will be added here when public.

## v0.9 — Public Beta (Current)

The following features are live in the current public beta:

- **Buy flow** — BRL via Pix → ZEC, SOL, ETH, or USDC
- **Sell flow** — crypto → BRL via Pix
- **Wallet support** — P2P.me smart account login; external wallet support via Rabby and Phantom
- **Quote transparency** — full fee breakdown presented before order confirmation
- **P2P.me ZK-KYC** — privacy-preserving KYC for users seeking higher transaction limits
- **NEAR Intents** — on-chain asset conversion from USDC to the user's target asset

<Note>
  v0.9 is a public test release. Some features depend on configuration or partner setup and may not be active in all environments. Behavior may change before v1.0.
</Note>

## Upcoming: v1.0

The following items are planned for the v1.0 release. This list will be updated as the roadmap is finalized.

- Additional fiat corridors beyond BRL/Pix
- Expanded NEAR Intents asset catalog
- Full KYC integration (configuration and partner-dependent)
- Stability, performance, and UX improvements based on beta feedback
